## 必须记住的 8 句话

1. **C# WinForms → C++/CLI OCCTProxy → OCC**；IO 用 netDxf 读取 DXF。
2. OCCTProxy **组合持有** OCC 对象，没有显式继承原生 OCC 类。
3. 工程配置和已检查的 Debug 内核 DLL 都是 **OCC 7.7.0**；仓库另有 7.9.3 目录。
4. `panel2D.Handle → WNT_Window → V3d_View`，宿主是二维面板，内核仍使用三维查看器。
5. `ConvertWithProj → 视线与 XOY 平面求交 → 模型点`，不能直接把像素当模型坐标。
6. 吸附 **顶点优先，边最近点其次**；半径 `max(abs(Convert(12)), tolerance×5)`。
7. `gp_Pnt → MakeEdge → AIS_Shape → GlobalShapeMap → C# 图层表`。
8. **吸附到边不等于打断旧边或形成共享拓扑**；取消当前线不等于删除已完成线。

## 演示顺序

导入已验证的平面 DXF → 普通图层右键 Make Current → 直线按钮 → 自由两点画线 → 端点吸附 → 远离端点的边吸附 → 右键取消 → 有起点时两次 Esc → 图层显隐 → 导出一个新的 STEP 文件。

灰十字＝自由点；黄圆十字＝吸附；青圆十字＝已定起点；橙黄线＝预览；红线＝已完成。

第一次点返回 1，完成返回 `[2, ID]`；0＝投影失败，-2＝两点过近，-3＝建边失败，-4＝ID 冲突。绘图结束一条后重新等起点，不会自动续画折线。

## 不能说过头的地方

- 当前入口读 DXF，不能据 `dwg-to-stp.exe` 名称说直接读 DWG。
- 自由落点在 Z=0；吸附缺少共面过滤，严格二维需要共面输入。
- STEP 是几何输出；当前不代表已生成有限元网格。导出设置关闭颜色与图层模式。
- 新线按第二点完成时的当前图层登记；两次落点间换图层也会影响这一条线。
- 本次检查基于源码和磁盘配置，未重新编译或运行验收；不要说已证明跨机器部署或大模型性能。
